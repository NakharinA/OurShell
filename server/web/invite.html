How to join

  1. Install the OurShell app: download it here (Windows, macOS, Linux).
  2. Open it and create your vault. Its master password is also your password on this server.
  3. Open Account & sync → Create account. Paste this invite link into the Server URL field (the server and invite code are filled in for you), enter your email and master password, and create the account.
