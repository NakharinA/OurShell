Database

OurShell stores its data in PostgreSQL. Everything users sync is encrypted on their devices first, so the database only ever holds ciphertext.

Server address

The address people enter in the OurShell app (Account & sync → Server).

The domain must already point at this server, and port 443 must reach this container from the internet. Skip this if you use your own reverse proxy (Synology, Caddy, nginx, Cloudflare Tunnel).

Who can create an account?

The first account anyone creates becomes the server's owner, so sign up yourself right after setup.

Admin password

Protects this server's admin page (/admin), where you change settings, create invites and manage users. It's separate from your OurShell account.
