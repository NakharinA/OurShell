Server address

How is it reached over HTTPS?

Point the proxy at this server's HTTP port and have it send X-Forwarded-For and X-Forwarded-Proto. Proxies on this machine, a Docker network or a private network are trusted; others can be added later on the admin page.

The domain must already point at this server, and public port 443 must reach this container's HTTPS port (the installer publishes it on port 3000: forward 443 to 3000 on your router).

Who can create an account?

The first account anyone creates becomes the server's owner, so sign up yourself right after setup.
