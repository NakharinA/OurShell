Reverse proxy / ingress

Turn this on when Caddy, nginx, Traefik, a Synology reverse proxy, a Kubernetes ingress or Cloudflare Tunnel terminates HTTPS in front of this server. It then believes X-Forwarded-For / X-Forwarded-Proto from trusted proxies only, and built-in HTTPS is off.

Encrypted backups to S3

Backs up the whole server (database and configuration, including the master key) as one encrypted file to S3-compatible storage: AWS S3, Cloudflare R2, Backblaze B2, Wasabi, MinIO, Synology C2 and others. A check runs every few hours; when nothing changed, nothing is uploaded.

Store the passphrase somewhere safe, away from this server. Without it, the backups can't be restored by anyone, including you.

Backups in the bucket
